# Как правильно экспортировать Netscape cookies для AmoCRM

## Проблема: 403 Access Denied

Если вы получаете ошибку **403 Access denied**, это означает, что:

1. **Отсутствует cookie сессии** - самая частая причина
2. **Cookies устарели** - нужно экспортировать заново
3. **Экспортированы не все cookies** - проверьте настройки экспорта

---

## Решение: Правильный экспорт cookies

### Способ 1: Использование расширения Cookie-Editor (РЕКОМЕНДУЕТСЯ)

#### Для Chrome/Edge:

1. Установите расширение **Cookie-Editor**:
   - Chrome Web Store: https://chrome.google.com/webstore (поиск: "Cookie-Editor")

2. Откройте **https://amoshturm.amocrm.ru** и авторизуйтесь

3. Убедитесь, что вы находитесь на странице AmoCRM (не просто залогинились, а зашли внутрь системы)

4. Кликните на иконку **Cookie-Editor** в панели инструментов

5. Нажмите на кнопку **Export** (обычно в правом верхнем углу)

6. Выберите формат **Netscape HTTP Cookie File**

7. Нажмите **Copy to clipboard** или сохраните в файл

#### Для Firefox:

1. Установите расширение **Cookie Quick Manager**:
   - Firefox Add-ons: https://addons.mozilla.org (поиск: "Cookie Quick Manager")

2. Откройте **https://amoshturm.amocrm.ru** и авторизуйтесь

3. Кликните на иконку расширения

4. Выберите сайт **amocrm.ru**

5. Нажмите **Export** → **Netscape format**

6. Сохраните в файл или скопируйте

---

### Способ 2: Использование curl (для опытных пользователей)

1. Откройте **DevTools** (F12) в браузере

2. Перейдите на вкладку **Network** (Сеть)

3. Обновите страницу AmoCRM (F5)

4. Выберите **любой запрос** к `amoshturm.amocrm.ru`

5. Кликните правой кнопкой → **Copy** → **Copy as cURL (bash)**

6. Вставьте команду в текстовый редактор

7. Найдите строку с `-H 'cookie: ...'`

8. Скопируйте значение cookies (всё после `cookie:`)

---

### Способ 3: Ручной экспорт через DevTools

1. Откройте **DevTools** (F12)

2. Перейдите на вкладку **Application** (Приложение)

3. В левом меню: **Storage** → **Cookies** → **https://amoshturm.amocrm.ru**

4. Вы увидите список всех cookies

5. **ВАЖНО**: Убедитесь, что видите cookie с именем типа:
   - `session`
   - `PHPSESSID`
   - `auth_token`
   - `SESSION_ID`
   - или подобный cookie с длинным значением

6. Если такого cookie нет - **вы не авторизованы**!

---

## Проверка правильности cookies

Правильный набор cookies для AmoCRM должен включать:

✅ **Обязательные cookies**:
- Cookie сессии (обычно с длинным значением вроде `eyJhbGciOiJIUzI1NiIsInR5cCI6...`)
- `user_lang` - язык пользователя
- Возможно `session`, `PHPSESSID` или аналогичный

✅ **Опциональные cookies**:
- `access_token_expires_at`
- `server_time`
- `LAST_PLACE_*` (настройки интерфейса)
- `sbjs_*` (аналитика)
- `gso_visitor_uid`

❌ **Недостаточно только**:
- Аналитических cookies (`sbjs_*`, `gso_*`)
- UI preference cookies (`LAST_PLACE_*`)
- Без cookie сессии доступ **НЕ БУДЕТ РАБОТАТЬ**!

## Пошаговая инструкция для получения РАБОЧИХ cookies

### Шаг 1: Полностью авторизуйтесь

```
1. Откройте новое окно браузера в режиме Инкогнито
2. Зайдите на https://amoshturm.amocrm.ru
3. Введите логин и пароль
4. ВАЖНО: Дождитесь полной загрузки интерфейса AmoCRM
5. Кликните по любому разделу (Сделки, Контакты и т.д.)
```

### Шаг 2: Экспортируйте cookies

Используйте один из способов выше (рекомендуется Cookie-Editor)

### Шаг 3: Сохраните в файл

Сохраните экспортированные cookies в файл `cookies.txt`

### Шаг 4: Запустите скрипт

```bash
python amocrm_netscape_export.py
```

Выберите вариант 1 (из файла) и укажите путь к `cookies.txt`

## Типичные ошибки

### Ошибка: "403 Access denied"

**Причина**: Отсутствует cookie сессии или он устарел

**Решение**:
1. Заново авторизуйтесь в AmoCRM
2. Экспортируйте cookies заново
3. Убедитесь, что в экспорте есть cookie сессии (см. "Проверка правильности cookies" выше)

### Ошибка: "401 Unauthorized"

**Причина**: Cookies устарели

**Решение**:
1. Получите новые cookies (см. инструкцию выше)
2. Cookies обычно действуют 24-48 часов

### Ошибка: "Найдено 0 cookies"

**Причина**: Неправильный формат файла

**Решение**:
1. Убедитесь, что файл в формате Netscape (с табуляциями между полями)
2. Проверьте, что первая строка: `# Netscape HTTP Cookie File`

## Альтернатива: Использовать Header String формат

Если Netscape формат не работает, попробуйте:

```bash
python amocrm_web_export.py
```

И вставьте cookies в формате HTTP заголовка:
```
session=abc123; user_lang=ru; access_token=xyz789; ...
```

```bash

```

Он покажет:
- Сколько cookies найдено
- Список всех cookies
- Результат проверки подключения к AmoCRM

## Безопасность

⚠️ **ВНИМАНИЕ**:
- Cookies дают **ПОЛНЫЙ доступ** к вашему аккаунту AmoCRM
- **НЕ ДЕЛИТЕСЬ** cookies с другими людьми
- Файл `cookies.txt` добавлен в `.gitignore` и не загрузится в git
- После использования удалите файл с cookies или храните в безопасном месте

## Дополнительная помощь

Если ничего не помогает:

1. Попробуйте другой браузер
2. Очистите cookies и кэш браузера, затем заново авторизуйтесь
3. Проверьте, что у вашего аккаунта есть доступ к API AmoCRM
4. Свяжитесь с поддержкой AmoCRM для проверки прав доступа
