# Приключения Грамотея

Интерактивная обучающая игра-бродилка для повторения материала по русскому языку.

## Описание

"Приключения Грамотея" - это увлекательная образовательная игра, в которой игрок путешествует по игровому миру, встречает различных персонажей (NPC) и выполняет задания по русскому языку. Игра охватывает основные темы:

- **Орфография** - правописание слов
- **Пунктуация** - постановка знаков препинания
- **Грамматика** - правила русского языка

## Особенности

- 10 уникальных персонажей с заданиями
- 10 разнообразных заданий по русскому языку
- Система прогресса с очками и уровнями
- Интуитивное управление
- Красивый интерфейс с анимациями
- Адаптивный дизайн

## Как играть

### Управление

- **Перемещение**: используйте клавиши-стрелки (←↑→↓) или WASD
- **Взаимодействие**: подойдите к персонажу и нажмите пробел (SPACE)

### Игровой процесс

1. Перемещайтесь по игровому полю с помощью клавиш управления
2. Персонажи с восклицательным знаком (!) имеют новые задания
3. Подойдите к персонажу и нажмите пробел для начала диалога
4. Выберите вариант ответа и нажмите кнопку "Ответить"
5. Получите очки за правильные ответы
6. Выполните все 10 заданий для победы

### Система прогресса

- За каждое правильно выполненное задание вы получаете **10 очков**
- Каждые 3 выполненных задания повышают ваш **уровень**
- С повышением уровня увеличивается скорость перемещения персонажа
- Персонажи с выполненными заданиями отмечены галочкой (✓)

## Запуск игры

1. Откройте файл `index.html` в современном веб-браузере
2. Игра запустится автоматически
3. Начните приключение!

## Технические требования

- Современный веб-браузер (Chrome, Firefox, Safari, Edge)
- Включенный JavaScript
- Рекомендуемое разрешение экрана: от 1024x768

## Примеры заданий

Игра содержит задания по различным темам:

1. **Орфография**: выбор правильного написания слов (посидеть/поседеть, чтобы/что бы)
2. **Пунктуация**: правильная расстановка запятых в предложениях
3. **Грамматика**: склонение существительных, правильное построение предложений

## Возможности расширения

Игру можно легко расширить:

- Добавить новые задания в массив `TASKS` в файле `game.js`
- Создать новых персонажей в массиве `NPCS`
- Изменить дизайн через файл `style.css`
- Добавить новые уровни сложности
- Реализовать систему достижений
